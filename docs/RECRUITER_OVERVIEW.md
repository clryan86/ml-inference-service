# Recruiter Overview

**ML Inference Service** is a complete ML-engineering portfolio project rather than a notebook-only model. It demonstrates reproducible training, evaluation, artifact management, typed inference APIs, batch scoring, model metadata, request persistence, feature drift monitoring, testing, Docker, and CI.

The model predicts synthetic equipment-failure risk, keeping the example safe and reproducible while showcasing skills relevant to ML engineering, backend Python, MLOps, and applied AI roles.
